# 📚 Gestor de Biblioteca con JavaScript

Mini proyecto desarrollado en JavaScript como parte del módulo de **Callbacks y JSON de DEV.F**.

## 📌 Descripción

Aplicación sencilla que permite gestionar una colección de libros, consultar su información y actualizar su disponibilidad, utilizando callbacks y JSON para simular operaciones asíncronas de lectura y escritura de datos.

## ⚙️ Funcionalidades

- Consultar los libros registrados.
- Agregar nuevos libros con título, autor y género.
- Actualizar la disponibilidad de un libro a disponible o prestado.
- Simular la lectura y escritura de datos mediante `setTimeout()`.
- Interactuar con el programa mediante un menú de opciones.

## 💻 Tecnologías

- JavaScript
- HTML5

## 🎯 Objetivo

Practicar el manejo de callbacks y datos JSON mediante una simulación de gestión de biblioteca, comprendiendo cómo ejecutar operaciones de manera asíncrona en JavaScript.

**Nota:** Los datos se almacenan temporalmente en memoria, por lo que se restablecen al recargar la página.
